# עדי – בית למתמטיקה · פלטפורמת הלומדה

מערכת SaaS מלאה ועצמאית: תלמידים נרשמים, עדי מאשרת ופותחת נושאים, והתלמידים לומדים, מתרגלים ונבחנים – הכל בכתובת אחת קבועה.
נושא חדש נבנה **אוטומטית** מ-PDF / תמונה / Word / קישור / טקסט בעזרת Gemini, ומופיע אצל התלמידים ברגע שמפרסמים – בלי לשנות קוד ובלי גרסה חדשה.

## מה יש במערכת

**לתלמידים**
- הרשמה → מסך "ממתין לאישור" שמתעדכן לבד ברגע שעדי מאשרת. קישור הזמנה לנושא (`/?topic=...`) פותח את הנושא ישירות.
- לובי אישי: רמה ו-XP, רצף ימים 🔥, יעד יומי, אוסף תגים, טבלת אלופים שבועית, גרף פעילות.
- לכל נושא 4 לשוניות: **הסבר** (פרקים, דוגמה פתורה עם חשיפת שלבים, סרטונים, תמונות, חוקר ציר מספרים) · **תרגול** (6 סוגי שאלות: אמריקאית, הקלדה עם מקלדת מתמטית, נכון/לא נכון, ציר מספרים, סידור, התאמה; רמז אחרי טעות ראשונה, פתרון מלא אחרי השנייה, קומבו ובונוסים, כפתור "עדי, נתקעתי!" לוואטסאפ) · **הטיפים של עדי** · **מבחנים** (טיימר אופציונלי, ציון, פירוט מלא, מבחן חוזר עם ערבוב).
- תצוגת נוסחאות KaTeX עם עברית מימין לשמאל, מותאם מלא למובייל.

**לעדי (מרכז הניהול)**
- לוח בקרה: ממתינים לאישור, פעילות 14 יום, "נורות אזהרה" (תלמידים מתחת ל-60% בתת-נושא), מי לא נכנס שבוע (+ תזכורת בוואטסאפ).
- לוח תלמידים בסגנון monday: סטטוס צבעוני, הרשאות לשכבה מלאה או לנושאים בודדים, איפוס סיסמה, ניתוק מכשירים, דף תלמיד מפורט.
- נושאים ותכנים: טיוטה/פרסום, שכפול, ייבוא/ייצוא JSON, קישור הזמנה.
- עורך מלא לכל פריט (תצוגה מקדימה למתמטיקה, סידור, שכפול, העלאת תמונות, אזהרות על שאלות לא תקינות, Ctrl+S).
- **סטודיו AI**: יצירת נושא שלם מקבצים/קישור/טקסט + "עוד שאלות עם AI" / "מבחן חדש עם AI" לנושא קיים.
- דוחות ציונים עם ייצוא לאקסל, סטטיסטיקת קושי לכל שאלה, גיבוי מלא.

**אבטחה**: סיסמאות מוצפנות (scrypt), עוגיות httpOnly, הגנת CSRF, הגבלת ניסיונות, עד 2 מכשירים לתלמיד, התשובות לא נשלחות לדפדפן – הבדיקה והציון מתבצעים בשרת, תלמיד רואה רק נושאים מפורסמים שנפתחו לו.

## הרצה מקומית

דרוש Node.js 22.13 ומעלה.

```bash
npm install
npm run build
npm start            # http://localhost:3000
```

בכניסה הראשונה המערכת מבקשת ליצור את חשבון המנהלת. הנושא "מספרים מכוונים" (32 תרגילים + 4 מבחנים) כבר טעון.

בדיקות: `npm test` (22 בדיקות אוטומטיות – הרשאות, ציונים, אבטחה, AI במצב דמה).

## העלאה לאוויר (Render – מומלץ)

1. מעלים את התיקייה ל-GitHub (ריפו פרטי).
2. ב-[render.com](https://render.com): **New → Blueprint** → בוחרים את הריפו. הקובץ `render.yaml` מגדיר הכל, כולל דיסק קבוע ל-`/data`.
3. אחרי ההעלאה נכנסים לכתובת, יוצרים חשבון מנהלת – ומדביקים מפתח Gemini במסך **הגדרות**.
4. (אופציונלי) מחברים דומיין, למשל `learn.adi-math.co.il`, בהגדרות השירות ב-Render.

> חשוב: חייבים דיסק קבוע (תוכנית Starter ומעלה). בתוכנית חינמית בלי דיסק – הנתונים נמחקים בכל הפעלה מחדש.

אפשר גם כל שרת שמריץ Docker (`Dockerfile` מצורף) – רק לחבר volume ל-`/data`.

## מפתח Gemini

[Google AI Studio](https://aistudio.google.com/apikey) → Create API key → הדבקה במסך ההגדרות → "בדיקת חיבור". המפתח נשמר בשרת בלבד.

## גיבוי

הגדרות → "הורדת גיבוי" (JSON של כל הנושאים, התלמידים והציונים). כל נושא אפשר לייצא בנפרד. מומלץ לגבות פעם בשבוע; הנתונים עצמם נמצאים בקובץ `data/adi-math.db`.
